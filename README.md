# 🦷 Website: Clinica de Odontologia da universidade

Desevolver um site para auxiliar na gestão da clinica odontologica, com obetivo de facilitar os cadastro e agendamnetos dos pacientes 
Projeto desenvolvido pelo grupo 1 - 4º semestre de Analise e Desenvolvimento de Sistemas - 2025
Universidade Brasil - Campus São Paulo

# Planejamento

Para proporcionar uma experiência alinhada às práticas do mercado, utilizamos metodologia ágil com práticas DevOps, organizando as atividades e o fluxo do projeto com Trello e Microsoft Office.
O projeto proporcionou experiência prática em desenvolvimento de software, organização de processos, trabalho em equipe e aplicação de boas práticas desde o planejamento até a entrega final.

Durante o desenvolvimento, realizamos:

- Definição da arquitetura do site com foco na experiência do usuário 
- Modelagem do banco de dados com Diagrama Entidade-Relacionamento 
- Implementação do banco de dados em MySQL
- Desenvolvimento Back-end e Front-end
- Elaboração de documentação técnica do sistema
- Realização de testes antes da implementação e entrega, garantindo qualidade, funcionamento adequado e redução de possíveis falhas.
